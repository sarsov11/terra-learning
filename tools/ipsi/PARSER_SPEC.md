# 대학별 파서 규격 (2028 시행계획 → 정리된 모집단위 데이터)

## 입력
- `python3 -I tools/ipsi/parsers/<id>.py <pdf경로> <출력경로>`
- PDF: 대학이 공표한 2028학년도 대학입학전형시행계획. 표는 pdfplumber(0.11.x)로 읽는다.
- 외부 라이브러리는 pdfplumber와 표준 라이브러리만. 네트워크 접근 금지.

## 출력 (`tools/ipsi/norm/<id>.json`, UTF-8)
```json
{
  "id": "snu",
  "이름": "서울대학교",
  "출처쪽": [5, 6, 7],
  "전형": [
    {"key": "수시_교과_지역균형", "시기": "수시", "유형": "학생부교과", "전형명": "지역균형전형", "군": null},
    {"key": "정시_수능_나", "시기": "정시", "유형": "수능", "전형명": "일반전형", "군": "나"}
  ],
  "모집단위": [
    {"단과대학": "경영대학", "모집단위": "경영대학", "계열": "인문",
     "인원": {"수시_교과_지역균형": 26, "정시_수능_나": 30}, "계": 100, "쪽": 5,
     "검증": "합계일치"}
  ],
  "메모": ["정원내만 수록", "의예과는 지역의사전형 별도"]
}
```
- `유형`은 다음 중 하나: 학생부교과, 학생부종합, 논술, 실기/실적, 수능, 기타
- `시기`: 수시 또는 정시. `군`: 정시일 때 가/나/다, 수시는 null
- `key`는 대학 안에서만 유일하면 된다(영문·한글 상관없음, 공백 없이).
- **정원내 모집인원만** 넣는다. 정원외(농어촌·기회균형 정원외·재외국민 등)는 넣지 말고, 넣지 않았다고 `메모`에 적는다.
  단, 정원내 기회균형/고른기회 전형은 넣는다.
- `모집단위`: 실제로 학생을 뽑는 가장 작은 단위(학과·학부·계열). 단과대학 소계·합계 행은 넣지 않는다.
- `계`: PDF 표에 그 행의 합계 칸이 있으면 그 숫자, 없으면 null.
- `검증`: 행의 전형별 인원 합 == `계` 이면 "합계일치", 다르면 "합계불일치", `계`가 null이면 "합계칸없음".
  `-`, 빈칸은 0으로 보고 `인원`에서 뺀다(0인 전형은 넣지 않는다).
- `계열`: PDF가 인문/자연/예체능/통합 등을 밝히면 그대로, 없으면 null. 추측하지 않는다.
- 숫자는 PDF에 있는 그대로. 추정·보정 금지. 읽을 수 없으면 그 행을 빼고 `메모`에 적는다.

## 검증(파서 작성자가 직접 할 일)
1. 모든 행에 대해 위 `검증` 계산.
2. 대학 전체 합: PDF에 정원내 총계(수시 계, 정시 계, 전체 계)가 있으면 정리된 데이터 합과 비교해 `메모`에 "총계 대조: 수시 n=n, 정시 n=n" 형식으로 남긴다.
3. 무작위 3행을 PDF 원문(해당 쪽 텍스트)과 눈으로 대조하고 결과를 보고서에 적는다.

## 금지
- git 명령(add/commit/push) 금지. 파일만 쓴다.
- 다른 대학 파일 건드리지 않기.
